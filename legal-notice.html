2. What the service is

MagAudit Agent is a GitHub App that checks the code in your pull requests, and the code already in your repositories when you install it, for potential security issues: exposed credentials, insecure code patterns and risky dependencies. It is installed from github.com/apps/magaudit-agent.

3. Terms of use, in short

The binding text is our Terms of Service. In short:

  • It is automated analysis, not a guarantee. The checks match patterns and query public registries. They can miss real problems and flag harmless code; findings are an aid to your own review, not a certification that your code is secure (Terms §2).
  • It acts only through GitHub. It reads what the permissions you approve allow, posts comments, suggested fixes and a check, and never pushes or merges code. Each permission and what we never do with it is listed on our trust page.
  • Acceptable use. Use it only on repositories you are authorised to audit, do not try to disrupt, overload or reverse-engineer the service, and do not resell it without a written agreement (Terms §3).
  • Limitation of liability. To the extent the law allows, we are not liable for indirect losses, and liability is capped at what you paid in the previous twelve months — never excluding wilful misconduct, gross negligence or anything the law does not let us exclude (Terms §6).

4. Your data, in short

The binding text is our Privacy Policy. In short:

  • The code of each pull request is read on one server in the EU and never written to disk; the diff is discarded when the audit ends.
  • The full report, which shows the flagged lines, lives in memory only for up to 7 days and is lost when the service restarts.
  • Your code is never sent to an AI model or to any third party: only package names and versions leave the server, to the package registries.
  • What we do store — installation, organisation, repository names, counts — is deleted when you uninstall, as the privacy policy details.
